# Response style import

The supplied `i-have-adhd` entrypoint declares MIT but provides no author,
source URL, revision, or full license text. Preserve its name and license
identifier without inventing provenance or an upstream evaluation result.

The Daedalus adaptation keeps a clear first action, manageable numbered tasks,
brief state reminders, visible completion and low distraction. The user chose
this style for most replies during the 2026-10-03 review. The main workflow
includes its short default to avoid an extra skill load on each response.

The adaptation removes unsupported slash-command activation, invocation-policy
metadata, guaranteed session persistence, universal statements about ADHD,
mandatory estimates and prose approval prompts. It preserves complete requested
coverage and the owning task's HTML/JSON/evidence contract. Loading the skill
does not create a durable user setting or authorize a memory write.

Catalog/resource round trips, tool alignment, prompt configuration checks and
local links validate integration. They do not measure live comprehension or
certify a medical intervention.
